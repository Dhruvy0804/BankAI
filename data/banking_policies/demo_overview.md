# Synthetic demo banking overview

This document is educational sample material for BankAI. It does not
describe a real bank's policies and is not financial advice.

## Demo scope

Accounts, transactions, cards, KYC records and loan results are fictional.
Never submit real bank credentials or identity documents.

## Demo card blocking

A signed-in customer must confirm the specific card before BankSim
changes its status to blocked. A request alone does not block a card.

## Demo loan applications

The demo uses fictional application inputs and does not require real
documents. Eligibility is a simulated result, not credit approval.
